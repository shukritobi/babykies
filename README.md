# Babykies storefront

SS Digital Lab ecommerce project. The repository contains the checkout backend and catalog source. The full V2 source package also contains the storefront, original screenshot-derived image assets, publishing launcher, and browser QA workflow. Upload that full package before configuring a Pages preview.

Production requires Cloudflare Workers, D1 and Babykies-approved CHIP merchant credentials. Payments remain disabled by default. Do not commit credentials, customer data, or enable payments until the full test-mode integration and merchant approval are complete.

Proposed commission: 15% of paid merchandise subtotal, excluding shipping, with refund and fee reconciliation. The ledger is not automatic split settlement. See full V2 package README for deployment details.
